## AS 91897 Irish Learning Program
A program that manages an Irish learning menu which allows the user to:
- see user profile and rank
- view vocabulary topics
- learn Irish through multiple choice questions
- quit program.

## Purpose
A robust, flexible program that uses functions to create an Irish learning program 
where they are able to view vocabulary lists, test their knowledge with translation quizzes, 
earn points, track error counts, and progress through user ranks.

## Executing program
How to run the program (Step-by-step)
- Enter menu option (0-3)
- View Profile (Username, rank, points and errors)
- View Vocabulary (English and Irish translations by topic)
- Learn (Multiple choice and written translation quiz)
- Exit program (Session total points and word challenge)

## Help
Make sure to enter numbers when picking menu selections or quiz choices.   
When entering written translations, check your spelling against the vocabulary lists.
